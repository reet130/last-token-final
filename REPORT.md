# Как мы находим подозрительные рамки

Исходный детектор уже назвал класс и координаты каждого объекта. Задача команды — выстроить его рамки в очередь для проверки. Например, если две исходные рамки обозначают одну кисть, хотя бы одна из них лишняя. Высокая уверенность детектора сама по себе такой дубль не обнаруживает.

## Как получаем оценку

1. Обучаем три YOLO11l с разными начальными seed на ручных рамках train. Каждый смотрит на исходный кадр и его горизонтальное отражение. Координаты после отражения переводим обратно. Получаем шесть прогонов одних и тех же трёх моделей.
2. Для каждого прогона сопоставляем рамки внутри одного кадра и класса. Принимаем рамки нашего детектора с уверенностью от 0.05. Для пары требуется IoU ≥ 0.60. Сначала максимизируем число пар, потом их суммарное перекрытие. Каждая рамка участвует только в одной паре. Доля прогонов, в которых исходному боксу не нашлось пары, — голос детекторов Y.
3. Для людей, у которых центр рамки по горизонтали расположен от 330 пикселей, добавляем голос публичной модели позы P. Он равен 1, когда на полном кадре у человека нет пары с уверенностью позы ≥ 0.5. В первом файле итоговый голос D = (6Y + P) / 7, во втором D = (Y + P) / 2. У окна слева и для остальных классов D = Y.
4. Дополнительно ищем признаки ошибки V. Для чашки проверяем подтверждение похожей посудой, для кисти — близость запястья, для человека — совпадение с рамкой скелета. Видимое колено или лодыжка существенно ниже исходной рамки тоже может поднять оценку человека. Если сработала хотя бы одна проверка, V = 1. Пороговые значения и обработка фрагментов кадра приведены в [коде экспертов](finalist/expert_veto.py) и [проверке позы](finalist/person_vote.py).

Итог для обеих версий: **score = (1 − уверенность исходного детектора + D + 2V) / 4**. Выход содержит исходный ID и оценку для оператора.

## Как оценивали и почему выбрали две версии

Ручная разметка доступна за два дня. Для прогнозов на 25 октября каждый детектор учился на 26-м и наоборот. Все рамки одного кадра оставались вместе. На каждом отложенном дне считаем Average Precision по метке ошибки среди исходных боксов оцениваемых классов. Столы исключены. Для test обучаем три итоговых детектора на обоих днях. Test обрабатывается автоматически.

Первый вариант дал лучший Public AP команды, 0.92465. Во втором изменили только вес голоса позы. Это поменяло оценки у 39 из 362 тестовых боксов, все они относятся к людям в зале. Вариант улучшил AP с 0.92579 до 0.93343 на первом дне и с 0.92565 до 0.93435 на втором, а на Public получил 0.92144. Поэтому в финал выбрали оба. Эти измерения характеризуют качество очереди на конкретных данных. При переносе на другую камеру особенно важно перепроверить границу зоны окна и геометрию проверок позы.
